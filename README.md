# LSOPC_RAGE_Study
Source data and analysis scripts for the manuscript: "A novel target of RAGE-V domain alleviates intestinal injury induced by ultra-processed food-derived AGEs".

# Software Used for Plotting
We used the following software to plot the figures from the provided source data:
- **Origin:** Used for plotting spectral curves and binding kinetics (Figure 1B, 1C, 1E).
- **GraphPad Prism:** Used for plotting bar charts, binding rate analyses, and statistical plots (Figure 1D, 1F; Figure 2B, 2E-2G, 2I, 2J).
